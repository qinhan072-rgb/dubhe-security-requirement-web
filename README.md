# DUBHE 智慧安防需求配置

一个用于客户填写智慧安防需求的本地 Web 原型。

## 功能

- 项目基本信息填写
- 按摄像头组新增、复制、删除
- 折叠式填写：进入页面时不会一次展开所有待填内容
- 每个摄像头组填写数量、位置备注、厂商、分辨率、接入方式
- 按功能类别选择 AI 识别能力
- 功能类别默认折叠，展开后再选择具体识别项
- 根据摄像头组名称和位置提示推荐功能，不自动勾选
- 项目级网络、AI、系统对接信息填写
- 附件上传
- 本地 SQLite 保存
- 导出 CSV / JSON

## 运行

需要 Node.js 24 或更高版本。

```bash
node server.mjs
```

打开：

```text
http://localhost:4173
```

## 数据位置

- 数据库：`data/requirements.db`
- 上传附件：`uploads/`

这些本地数据默认不会提交到 Git。

## 说明

当前版本不包含登录。后续可以在项目列表、保存接口和附件接口前增加登录校验。
