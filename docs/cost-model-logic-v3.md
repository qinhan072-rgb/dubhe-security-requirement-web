# 智慧安防成本选型逻辑 v3

V3 的目标是减少填表复杂度，把“需要动态填写/维护”的内容放在前面，把解释和总览放到后面。

## 需要填写或维护的页

### 01 项目参数输入

每个项目都需要看这一页。

- 动态参数：安全余量、算法研发成本系数、算法算力优化系数、数据复用/沉淀系数、视频融合风险系数、标准平台成本、AI Agent 接入成本。
- 摄像头组：组名、路数、分辨率、厂商/型号、接入复杂度、输出/融合要求。

其中“算法研发成本系数、算法算力优化系数、数据复用/沉淀系数”用于体现大模型成熟、算法复用、样本沉淀后带来的成本下降。

### 02 功能需求输入

每个项目都需要看这一页。

- 按摄像头组选择功能。
- 填交付口径：标准算法、场景规则配置、样本微调、新目标定制、仅 AI 研判。
- 填 AI 研判策略：沿用默认、不需要、可选、建议、必须。

### 03 成本参数库

不是每个项目都要改，但工程/产品负责人需要定期维护。

- 分辨率倍率。
- 功能算法成本参数。
- 视频融合参数。
- 硬件档位参数。

## 自动计算页

### 04 计算明细

不用填写，用来追溯每个成本从哪里来。

### 05 报价汇总

先看这一页判断整体是否合理，再回前 3 页调参数。

## 说明页

### 06 逻辑说明

只保留口径解释，不作为填表入口。
